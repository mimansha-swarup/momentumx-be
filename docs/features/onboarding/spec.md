# Channel onboarding

Onboarding gives each channel its own niche, audience, brand and content context. A person can own or join several channels; setup belongs to the selected channel rather than their login identity.

## Creator flow

1. Paste a YouTube channel URL to get suggested niche, audience and brand, or enter niche and audience manually.
2. Review the suggestions and try an initial idea batch.
3. Save the channel setup. Optional enrichment runs separately, so a slow YouTube or website lookup does not hold up the initial save.
4. Add competitors, website, description and format over time. Completeness highlights missing context; refresh retrieves newer public signals.

Prefill suggestions are not saved until confirmed. A failed enrichment request should not be presented as loss of an already saved form. Editors and owners can change setup; viewers can read the channel profile.

## Scope and limits

Personalization uses available context and can be incomplete when public lookups fail. Connection uses public channel URLs, not private YouTube analytics. Refresh is on demand; there is no scheduled refresh flow.
