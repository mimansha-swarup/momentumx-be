# Title and packaging

Title chooses the publishing headline. Packaging prepares the supporting description, thumbnail concepts and Shorts script. They share a project so each asset can use the context already available.

## Creator flow

1. Generate three title alternatives from a script, compare their editorial scores and reasons, and select the headline.
2. Generate a description, thumbnail concepts and Shorts independently.
3. Edit text, choose a thumbnail concept, or regenerate an individual asset.
4. Export the package when ready.

The selected title becomes the project display title. Scores express editorial judgment, not predicted CTR or views. Thumbnail concepts are text briefs, not rendered images.

Creators can enter through these tools before completing every earlier step. Title and Shorts still need script content; descriptions and thumbnail concepts can start from a title. A project supplies saved context when available.

## Saved work and review

Generation linked to a project saves its result. A preview without a project needs an explicit save to become project work. Save carries edits and selections; it does not clear a warning that upstream content changed.

Packaging completion covers description, thumbnail concepts and Shorts. Title completes separately when a headline is selected. Changed ideas, scripts, hooks or titles can make dependent work need review. Regenerate outdated assets or explicitly keep them as-is. Regeneration can reset a selection because the old alternatives have been replaced.

## Scope and limits

The creator remains responsible for reviewing claims, links, visual feasibility and publication suitability. The product does not render thumbnail images, publish to YouTube or provide private performance analytics. Editors and owners can create/change assets; viewers can read and export.
